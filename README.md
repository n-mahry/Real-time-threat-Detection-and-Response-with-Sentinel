# Real-Time Threat Detection with Microsoft Sentinel

This project demonstrates how to detect and respond to brute-force attacks using Microsoft Sentinel, including automated response with Logic Apps.

---

## What You’ll Learn

- Set up Microsoft Sentinel with Log Analytics
- Simulate a brute-force attack using an Azure VM
- Detect the attack with KQL
- Respond automatically with Logic Apps
- Visualize attacks in dashboards
